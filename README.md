# Catanos Cup

MVP de fútbol arcade original para navegador. Se publica como sitio estático en Vercel.

## Desarrollo

```bash
npm install
npm run dev
```

## Publicación en Vercel

1. Sube este directorio a un repositorio de GitHub.
2. En Vercel, importa el repositorio.
3. Vercel detectará Vite: usa `npm run build` y publica la carpeta `dist`.
4. Pulsa **Deploy**. No requiere variables de entorno ni backend.

## Controles

- `A` / `D` o flechas: mover
- `W` / flecha arriba: saltar
- `Espacio`: patear

En móvil aparecen controles táctiles.
